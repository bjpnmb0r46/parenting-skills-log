# “多囊”孕后，医生说要保胎，真的有必要吗？

> 更新时间：2026-09-16 (UTC+8)

“主任，我孕前虽然有多囊，但现在都已经怀上了，为什么还要进行保胎治疗啊？”经常有“多囊”女性怀孕之后疑惑这个问题。“多囊”孕后保胎真有必要吗？

多囊卵巢综合征属于内分泌和代谢异常疾病，通过治疗，实现怀孕的几率很高，但怀上不是关键，生得下才是最终目标。根据临床数据，患有多囊卵巢综合征的人群在孕早期流产的概率要比普通孕妇高。“多囊”常引起一系列代谢紊乱和并发症，如胰岛素抵抗、糖耐量异常、血压升高、代谢综合征等，因此PCOS女性即使受孕，流产和妊娠并发症的风险亦增加，那多囊卵巢综合征女性应该怎么保胎，顺利生下健康可爱的宝宝呢？

**高雄激素**

卵泡成熟依赖于体内的雌孕激素，但“多囊”患者常表现为高雄激素，雌激素不足，卵泡生长过程中雌激素供应不足，就容易排卵障碍，就像是种庄稼，“种子”不达标，庄稼怎会长得好？

其次，雄激素高容易导致子宫内膜对胚胎的容受性比较差，不利于受精卵的着床，着床后早期会因为激素紊乱而导致胚胎着床不稳，造成流产。另外，雄激素增高容易导致血小板聚集增高，这样怀孕后容易供血不足，导致流产。

**胰岛素抵抗**

胰岛素抵抗也是“多囊”患者的常见症状之一。胰岛素增高容易激活血小板，血小板聚集增高，同时促进同型半胱酸增高，也会导致供血不足进而流产。胰岛素增高还会刺激子宫内膜增生，内膜容受性下降，胚胎不容易在子宫内 “生根发芽”，也会流产。

胰岛素抵抗和肥胖的女性容易使纤溶酶原激活抑制物增高，这个指标就提示体内易形成血栓，易供血不足导致流产。

**心理因素**

多囊女性因为肥胖、不孕、治疗过程漫长等因素，往往需要承受较大的经济压力和精神压力，一些患者会有恐惧，焦虑等表现，这些情绪会导致女性内分泌进一步紊乱，不利于怀孕的维持。

**按时产检**

PCOS孕妇妊娠期糖尿病的发病率是普通孕妇的数倍，因此在24-28周需要进行糖尿病的筛查，评估是否是继发妊娠期糖尿病的风险，根据生殖科医生建议控制血糖。

PCOS的孕妇妊娠期高血压疾病发生率为5%，如果BMI>30，且高龄>35岁，就是子痫前期的高危人群了，要注意提前干预。

**孕酮补充**

孕激素保胎治疗主要适合于黄体功能不足、先兆流产、曾经有过自然流产史、高龄孕妇以及多囊卵巢综合征妊娠的女性。PCOS属于内分泌失调性疾病，怀孕后体内孕激素水平较低，易导致流产，所以一般需要做好保胎。

在医生指导下适当补充天然的孕激素，但不能盲目用药。孕酮选择可以口服、阴道用药或肌肉注射。

**早干预、早筛查、早治疗**

在未孕前要进行生活方式干预，如控制饮食，增强运动，积极减重等。

怀孕后进行定期的HCG、孕酮测定及B超检查；黄体功能支持治疗；如有妊娠期糖尿病需进行饮食控制及降糖治疗等。

对有2次以上流产的多囊卵巢综合征女性，建议进行病因筛查后针对性保胎。

**改善生活方式**

1.积极调整饮食：PCOS患者在怀孕初期，饮食以清淡为主，不能盲目进补；改变不良的饮食习惯，戒烟、少酒、少咖啡。

2. 适当运动：适量规律的运动，不仅能有效改善胰岛素敏感性，帮助维持正常血糖水平，还能影响神经内分泌系统，改善整体代谢水平。

3. 保持心情愉悦：心理状态（如压力、沮丧和抑郁等）会影响宝宝发育，因此保持美丽的心情很有必要哦！

二十岁出头的小田，曾经自然怀孕两次，但都分别在孕7周和孕9周时胎停流产。连续两次失去了当母亲的机会后，小田到某医院进行检查和治疗，确诊为“多囊卵巢综合征”和“双侧慢性输卵管炎”。可惜的是，经过一系列促排卵治疗，小田都未能受孕……
